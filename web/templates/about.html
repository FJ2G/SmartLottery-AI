关于项目

基于历史数据挖掘的双色球趋势分析工具

📊 数据管理

历史开奖数据存储，自动化抓取更新，SQLite 持久化

📈 统计分析

号码频率、奇偶分布、大小分布、区间分布，多维度分析

🎯 智能推荐

热号、遗漏、共现、K-Means 聚类，多策略加权混合推荐

📉 可视化

热力图、折线图、饼图、条形图，多图表在线展示

技术栈
Python 3.10+ FastAPI Rich SQLite scikit-learn matplotlib pandas NumPy Jinja2
命令行使用
$ python main.py update-latest    # 抓取最新数据
$ python main.py record --n 100   # 查看最近100期
$ python main.py chart all        # 生成图表
$ python main.py recommend -g 5  # 生成5组推荐
$ python main.py serve --port 8080 # 启动 Web
⚠ 本工具仅供数据分析与趋势研究，不构成投注建议。彩票为随机事件，请理性购彩，量力而行。
